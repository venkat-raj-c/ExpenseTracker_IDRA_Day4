# Expense Tracker

## Description

A simple Python Expense Tracker that stores expenses in a CSV file.

## Features

- Add expenses
- View all expenses
- Calculate total expenses
- Calculate expenses by category
- Add optional notes

## Technologies

- Python
- CSV File Handling

## How to Run

```bash
python expense_tracker.py
```

## Menu

```text
1. Enter expense
2. View expenses
q. Quit
```

### Enter Expense

Enter:

- Date
- Category
- Amount
- Note (optional)

Example:

```text
Date: 29-06-2025
Category: Food
Amount: 400
Note: Fun
```

### View Expenses

Displays all saved expenses along with:

- Total amount
- Amount spent for each category
